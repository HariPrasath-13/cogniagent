CogniAgent — End-to-End System Workflow Architecture

Complete technical blueprint from User Login to Grounded RAG Assessment, AI Tutor & Database schema
1. User Login
Options: Sign In / Sign Up
Tech Stack: Next.js (App Router), FastAPI, Passlib (bcrypt hash), Python-JOSE
Security Feature: 2-Step OTP Verification via Gmail SMTP / Resend API (300s expiry, rate limited)
DB: users, otps, sessions
➔JWT Token
2. Landing Page
Dashboard Overview: Student Info, Email verification badge, Profile score
Cognitive Metrics: Overall score, assessment counts, topic mastery level
Actions: Upload Study Material, Start Quiz, AI Tutor, Study Plan
Next.js Dashboard
➔Upload PDF
3. PDF & Deep NLP
Upload: PyPDF parser (up to 10MB limit), text cleaner
NLP Pipeline Steps:
• Tokenization: Sub-word byte-pair encoding
• Embeddings: Dense semantic vector spaces
• Positional Encoding: Token order awareness
• Transformer Layer: Multi-Head Self Attention mapping chunk relations
DB: user_documents
➔Context RAG
4. Grounded RAG Generator
Phi Model Flaw: Small context window & hallucinations on multi-topic PDFs
Qwen Model Flaw: High inference latency & verbose unformatted output
Cogni Custom Advantage: Zero hallucination, strict context grounding & JSON format
Assessment Features:
• Timed Assessment: Live countdown timer, time tracking, auto-submit
• Difficulty Levels: Easy, Medium, Hard, Adaptive
• Evaluation: Real-time automated scoring & feedback
DB: assessments
5. Interactive AI Tutor Module
Technology: FastAPI Router + LLM Stream Engine + Context Matcher
Functionality: Clarifies complex conceptual doubts using exact excerpts from uploaded materials.
Key Feature: Grounded citations (shows source page and text snippet). Post-exam mistake analysis.
DB: tutor_messages (stores chat history & cited sources)
6. Adaptive Study Plan Module
Technology: Python Curriculum Optimizer (study_plan.py)
Functionality: Identifies conceptual weaknesses from quiz mistakes and creates day-by-day tailored revision schedules.
Key Feature: Daily study milestones, dynamic re-assessment checkpoints, progressive difficulty ramp-up.
DB: study_plans (stores curriculum targets & completion status)
Database Architecture — SQLite (auth.db) & Data Flow Mapping
users & sessions: Stores user profiles, bcrypt password hashes, verification flags, and active bearer session tokens.
otps: Manages 6-digit verification codes, expiry timestamps (5 min), and failed attempt limit counters.
user_documents & assessments: Stores extracted PDF text, generated question JSON, student answers, timers, and test scores.
tutor_messages & study_plans: Persists two-way student-tutor dialogue, document citations, and dynamic study roadmaps.
